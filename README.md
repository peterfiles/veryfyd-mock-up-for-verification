# Veryfyd Verification UI Prototype

Interactive UI-only prototype for the Veryfyd verification flow.

## Implemented Level 2 flow
- Level 2 active; Levels 3, 4, and 5 visible but locked.
- Government-issued Primary ID selection.
- Secondary ID selection.
- ID number input and simulated photo/gallery upload.
- Manual video verification simulation.
- Review & Submit screen.
- Submission progress animation.
- Verification Under Review / admin review state.

Open `index.html` in a browser. No real documents or videos are uploaded or stored.
